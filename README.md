# ちびかま！（仮）

チン・ビン・カン・マンの4リールを止めて役を作る語感スロット。

▶ **[ここで遊ぶ](https://aideahandesen-dvs.github.io/chibikama/)**

## 遊び方

- スペース、または「レバーを叩く」で回転開始
- スペース連打で左から順にストップ。`1`〜`4` キーで好きなリールを狙い撃ち
- 面倒なら「オート停止」

## 配当表

| 並び | 役名 | 点 |
|---|---|---|
| ビンビンチンチン | **ちびかま！** | 12,000 |
| ビンカンチンチン | 敏感 | 10,000 |
| チンビンカンマン | 完全体 | 8,000 |
| 上記以外 | ハズレ | -50 |

この3役以外は全部ハズレ。当たるのは256回に3回。

スコアはマイナスまで落ちる。借金しても回せる。

## 中身

`index.html` 1枚だけ。ビルドもサーバーも要らないので、ファイルを保存してダブルクリックしても遊べる。
